# VeganHearts Development Files

## Structure

### `/scripts/`
Infrastructure setup and deployment scripts (numbered for execution order)

### `/documentation/`
- `ENV-VARS.md` - Environment variables reference
- `PASSWORD-SETUP-FLOW.md` - Password setup system documentation
- `TESTING-GUIDE.md` - Testing procedures
- `API-STATUS.md` - API endpoints overview

### `/progress_reports/`
Feature-specific progress reports organized by feature

### `/completed/`
Historical completion reports and milestones

### `/archive/`
Old/deprecated files kept for reference

### `/docs/`
Project documentation and planning

## Quick Reference

**Start Dev Server**: `PORT=3001 npm run dev`
**Deploy**: User handles manually
**AWS Profile**: Always use `--profile peterdonaghey`
